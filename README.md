# 🌎 Discover Travel Explorer

Travel Explorer brings together two sides of travel:

### 🇵🇰 Local Adventures

Explore destinations across Pakistan through dedicated travel experiences.

`Hunza` · `Skardu` · `Kashmir` · `Naltar` · `Fairy Meadows` · `Arang Kel` · `Ratti Gali`

### 🌍 International Escapes

Discover selected destinations beyond Pakistan.

`Switzerland` · `Maldives` · `Greece` · `International Tours`

# ✨ Features

| Feature | Experience |
|:---|:---|
| 🏔️ **Destination Discovery** | Dedicated pages for travel destinations |
| 🔎 **Dynamic Search** | Search and filter available tours |
| 📊 **Live Results** | Matching results update dynamically |
| ✈️ **Custom Trip Planning** | Enter personalized travel preferences |
| 📝 **Interactive Forms** | Handle and validate user input |
| 📧 **Email Opt-In** | Request confirmation through the trip flow |
| ✅ **Confirmation Flow** | Receive visual confirmation after planning |
| ☰ **Responsive Navigation** | Mobile-friendly menu interaction |
| ↑ **Back to Top** | Convenient long-page navigation |
